# dedup — поиск дубликатов файлов по содержимому

Консольная утилита: обходит каталог, считает BLAKE3-хеш каждого файла, находит совпадения и предлагает
удалить лишние копии.

## Что делает

1. рекурсивно собирает файлы из каталога `foo/` через `walkdir`;
2. считает для каждого файла хеш BLAKE3 (функция `shafile`);
3. попарно сравнивает хеши — совпадение означает дубликат;
4. для каждой найденной пары спрашивает в stdin: `Удалить файл? Y - Да, N - Нет`;
5. удаляет подтверждённые файлы (`fs::remove_file`).

## Как запустить

```bash
cd dedup
cargo run
```

Проверять можно сразу: в репозитории есть тестовые файлы `foo/test.txt`, `foo/test3.txt` (одинаковое
содержимое `privet`) и `foo/test2.txt` (`privet2`) — утилита найдёт одну пару дубликатов.

## Техника

- `blake3` 1.8 — хеширование, `walkdir` 2.5 — обход дерева;
- ошибки обхода возвращаются через `Result<(), Box<dyn Error>>` и оператор `?`;
- интерактивное подтверждение читается из stdin, так что случайных удалений без ответа не будет.

## Честные ограничения

- алгоритм **O(n²)** и хеш пересчитывается на каждую пару — для больших каталогов нужно считать хеши
  один раз и группировать файлы по хешу через `HashMap`;
- каталог `foo` зашит в коде, CLI-аргументов нет;
- функция называется `shafile`, хотя считает BLAKE3 (наследие первой версии);
- в `main()` и `shafile()` есть `unwrap()`, остался отладочный `println!("{}", guess == "Y")`;
- в список на удаление попадают только имена файлов, поэтому одноимённые файлы из разных подкаталогов
  могут перепутаться — правильнее хранить полные пути.
